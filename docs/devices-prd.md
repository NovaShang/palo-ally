# PaloAlly · 电脑与设备 PRD

2026-10-16。

## 1. 一句话

切换助理和管理配对都搬到左边的列表：第一行是现在的助理，有几台电脑时点它的名字切换；最后一行「电脑与设备」管电脑和连着它的设备。

## 2. 已定（主人选了方案 A）

1. **列表第一行**是当前的助理（Palo）。
   - 只配了一台电脑：和现在一样，没有箭头。
   - 有几台：名字旁边一个 ⌄。点名字弹出系统菜单：
     - 每个助理一行，写成「Palo（家里的 Mac）」，助理名加电脑名；当前的打勾，有未读或等你的带一个点；
     - 分隔线；
     - 「电脑与设备…」。
   - 选一个就切过去，和以前的切换一样。
2. **列表最后一行**总是「电脑与设备」（desktopcomputer 图标，次要颜色），点进去是一页。
3. **去掉旧入口：**
   - 管理界面（点小球进去的那页）里的「切换助理」；
   - 设置里的配对、换一台电脑、添加另一台电脑、我的助理。设置只留和这个 App 本身有关的。
4. **大多数人只有一台电脑：**除了最后那一行安静的「电脑与设备」，看不到任何多电脑的东西。

## 3. 电脑与设备

- **「我的助理」一节：**每台配对的电脑一行。
  - 名字、电脑、在线还是离线（离线时写最后在线的时间），当前的打勾。点一下切过去。
  - 长按（Mac 上右键）或左滑：重命名（只改这台设备上看到的名字）、解除配对（原地确认）。
  - 最后一行「添加另一台电脑」：走现有的配对流程，iPhone 扫码，Mac 粘贴或点链接。
- **「连着这台电脑的设备」一节：**当前电脑配对过的设备。
  - 名字、平台（知道的话）、最后在线；这台设备标「这台」。
  - 别的设备可以移除，先确认。这里不能移除这台自己，那是上面的「解除配对」。
  - 最后一行「添加设备」：调 `pair.invite`，显示二维码和链接（拷贝、共享）、还剩多久，和一句「用另一台设备扫码，或者在那台设备上点开链接」。

## 4. 主机

- 新的 `device.list` 和 `device.remove{deviceId}`：只给主人自己配对的设备和本机命令行，Ally 永远不行。以前的 `devices.list` / `devices.remove` 只在本机 socket 上，留给命令行。
- `device.list` 返回 `{devices: PairedDevice[]}`，`PairedDevice` 是 `{deviceId, label, platform?, pairedAt, lastSeen?, online, current}`。这台在最前，其余按最后在线排。
  - `platform` 来自那台设备 App 的 `hello{client}`（ios / mac），连过以后才有。记在 `state/device-meta.json`。
  - `lastSeen` 取连上的时刻和每次 hello 里较晚的那个；`online` 是现在连着。
- `device.remove`：断开那台设备的连接，让 relay 忘掉它，记审计 `device.removed`。
  - 移除的是自己：报错「这是你正在用的这台，要断开它请用「解除配对」」。
  - 没有这台设备：报错。

## 5. 验收

1. 一台电脑：列表第一行没有箭头，最后一行是「电脑与设备」，别处看不到多电脑的东西。
2. 两台电脑：点第一行的名字弹出菜单，选另一个就切过去。
3. 「添加设备」显示二维码和链接，倒计时在走。
4. 移除一台设备先确认；这台自己没有移除。
