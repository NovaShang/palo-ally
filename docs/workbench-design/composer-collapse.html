会收起的输入框

没在打字、也没有草稿时，输入框收成两个玻璃圆钮：左下 ＋（附件），右下 🎙（按住说话，点一下打字）。对话一直铺到底。要打字时，麦克风那颗圆钮像液体一样拉长成完整的输入框；清空并离开时再缩回去。像苹果新系统里底部标签栏的搜索按钮展开成搜索框。

1. 平时、开始打字、打着字

2. 有草稿就一直展开；按住说话

3. 分屏里：只有当前格显示圆钮

细节
  • 收起：草稿为空、输入框没有焦点、没有附件、没在录音。两颗 36pt 的玻璃圆钮贴着格子左下、右下（单个会话页是 44pt），之间什么都没有；对话的最后一行从圆钮之间穿过，底部只有很淡的渐隐。
  • 展开的方式，任一都行：① 点 🎙（和手机「轻点打字」一样）；② 当前格直接开始敲键盘，第一个字就让它展开并接住这个字；③ 按 Return 或 ⌘L 聚焦输入框；④ 拖文件或图片进来；⑤ 点 ＋ 选了附件。
  • 展开后：🎙 那颗拉长成输入框（同一块玻璃变形，0.25 秒），＋ 留在左边独立一颗。框里右边：没字时是 🎙，有字时变成发送。按住 🎙 仍然是按住说话。
  • 缩回：发送后、或清空后离开（点到对话里、按 Esc、切到别的格），且没有草稿，就缩回两颗圆钮。有草稿就保持展开，框里显示草稿。
  • 按住说话：收起状态下直接按住 🎙 就开始，不需要先展开；上方弹出「取消 / 编辑」，松手发送，和现在一样。
  • 分屏：只有当前格显示两颗圆钮；其他格什么都不显示，对话铺满。鼠标移到某格上，它的两颗圆钮淡淡出现，点了就切到这格。
  • 范围：先做 Mac（分屏格子和单个会话页）。手机要不要一样，你看了效果再定。
