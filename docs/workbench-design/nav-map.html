四、问题清单

  1. agent 分成了两种。侧栏「会话」里，Palo 开的 agent 和外部会话是两种东西：外部会话只读、有单独的页面、要「接管」才能说话。按新定义它们都是 agent，区别只是能不能在这里发消息。
  2. 等你的东西散在对话里。提问、权限、提议、好友草稿各有各的卡片样式和按钮，「等你的事」又把它们收成一份列表，同一件事有两处可以回答。
  3. 「目标和定时」「办过的事」「backlog（要做）」三个都跟「要做的事」有关，放在不同地方：前两个藏在「关于助理」里，backlog 还没做。任务这个词也在这里用作「办过的事」，跟刚定的「任务 = 后台在跑的」冲突。
  4. 工作区只是布局。它没有自己的东西（没有 backlog、成果、归档），手机上打开只是一个 agent 列表。
  5. 详情有两层。助理：详情 → 关于助理；agent：详情 → 关于这个会话。先看哪层、东西放哪层，用户分不清（「此刻」和「长期」是我们内部的分法）。
  6. 「先不看了」有三种。更早的会话（不常用自动收起来）、历史记录里的「收起来的」「已结束」、等你的事里的「收起」。按新定义都该是「归档」。
  7. 成果有两个范围。右侧栏成果默认「这个会话」，可切「全部」；工作区的成果没有自己的范围。
  8. 助理和 agent 的详情不对称。都有记忆（CLAUDE.md），只有助理能看能改。
