Mac 分屏：重新设计

一个窗口，几块平铺的面板，像编辑器的分栏：没有卡片、没有圆角、没有发光，面板之间一条细线。每块面板顶上一行窄标题：状态球 + 名字 + 它在干什么。当前那块顶上一条蓝线、标题底色淡蓝，别的面板内容稍微变淡；在等你的那块标题是淡橙。

A. 整个窗口只有一个输入框（推荐）

输入框在最下面横跨所有面板，左边写着发给谁（「→ 博客改版」）。点哪块面板，就发给哪块；⌘⌥←/→ 切换。面板里不再各有一个输入框，内容区多出一大块。

B. 每块面板一个矮输入框

每块面板底部一个 32pt 高的单行输入框，打字时才长高。直观，但面板多了还是挤。

C. 调整布局

拖面板之间的细线调宽窄：拖的时候只有一条蓝线跟着走，松手才重排。拖一块面板的标题到另一块上，交换位置。右上角几个布局按钮一键排成：左右两栏、三栏、上下、2×2。关闭和展开放在标题行最右边，鼠标移上去才出现。
和现在比
  • 去掉：每格的圆角卡片、边框发光、浮在内容上的胶囊头、右上角两个圆按钮、每格一个大输入框（A 方案）。
  • 当前面板一眼看出：顶上蓝线 + 标题淡蓝 + 其他面板变淡。蓝色只用在这一处。
  • 性能上也更轻：没有每格的玻璃和阴影；输入框只有一个，打字只动一处。另一个子任务在查架构上的卡顿，如果需要重写会一并给出方案。
