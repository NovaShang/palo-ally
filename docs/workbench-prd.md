# PaloAlly · 工作台 PRD

2026-10-18。PaloAlly 要成为主人日常使用 Claude Code 的环境，逐步取代 Bento Term。本文取代 `pals-prd.md` 里的导航和「帮手」这个说法；Pal 由主机 host、跟 Palo 互相传话这些机制继续有效。

设计稿：成果里的「工作台设计稿」（`~/.paloally/home/artifacts/workbench-design/index.html`）。本文和设计稿有出入时，以本文为准。

## 1. 一句话

一个助理（Palo），加上一组 Claude Code 会话。会话默认各自独立；想并排看几个会话时，就建一个**工作区**，把它们平铺在一起。Mac 和 iPad 是同一套工作台；iPhone 用同一棵树，但一次只看一个对话。

## 2. 概念和叫法

| 概念 | 界面上的叫法 | 说明 |
| --- | --- | --- |
| 主助理 | Palo（用户起的名字） | 只有一个。 |
| 会话 | 会话 / Session | 就是现在主机 host 的 Pal：一个文件夹里的一个 Claude Code 会话。界面上**不再出现「帮手」「Pals」**这些词。 |
| 工作区 | 工作区 / Workspace | 用户自己建的一组会话，打开后平铺显示。**不要**叫板、board、项目。 |
| 以前的 | 以前的 / Earlier | 结束了的、或者几天没动的普通会话。点开能接着聊。 |
| Allies | Allies | 家人朋友，就是现在的 Allies。 |

规则：
- 一个会话最多属于一个工作区。
- 会话默认不在任何工作区里，叫「普通会话」。
- 普通会话几天没动（默认 3 天），自动收进「以前的」。工作区里的会话不会自动收起。
- 在工作区里关掉一格，就**结束这个会话**，进入「以前的」。
- 不写代码的用户从来不需要碰「工作区」：他们的会话都是 Palo 开的普通会话。

## 3. 状态

每个会话有一个状态，在所有地方用同一个圆点表示：

| 状态 | 颜色 | 什么时候 |
| --- | --- | --- |
| 在干 | 青色（带一圈淡光） | 正在跑 |
| 等你 | 橙色 | 问了问题，或者在等批准。只有它用醒目的颜色 |
| 做完了 | 绿色 | 做完一件事，主人还没看过。在 Mac 或手机任意一处点开看过，就变成闲着，两边同步 |
| 闲着 | 灰色 | 没事 |

- 工作区那一行汇总写「N 等你」。
- Palo 那一项写「N 个会话在等你」。
- 任何会话变成「等你」，手机都会收到通知。

## 4. 侧栏（Mac / iPad），也是 iPhone 首页的那棵树

从上到下：
1. **Palo**：特别大的一项，小球在这里，状态动画也在这里。下面一行写它刚做了什么。
2. **工作区**：节标题右边有 ＋。每个工作区可以展开，下面列出它里面的会话。
3. **会话**：普通会话，按最近活动排序。最后一行是「以前的 N」。
4. **Allies**：在最下面。
5. **底部**：左边 ＋（菜单：新建会话、新建工作区），右边设置。

侧栏每一行的样子：状态点、名字；右边是时间或数量。工作区那一行有展开箭头和工作区图标。

## 5. 主区域的三种状态

### 5.1 选中 Palo
沉浸式的整块对话，和现在差不多。

### 5.2 选中一个会话（普通会话，或者工作区里的某一个）
和 Palo 页**完全一样**，只是对话的对象换了。

### 5.3 选中一个工作区
工作区里的会话全部平铺：
- 每一格就是一个完整的对话，带自己的输入框和长按说话。
- 正在用的那一格，边框用主题色。说话和打字都进这一格。
- 每一格左上是浮着的标题胶囊（状态点、名字、状态），右上是「放大成整页」和「关掉」。
- 分隔线可以拖动；把一格的标题胶囊拖到另一格上，可以交换位置或停靠在旁边。
- 工具栏：工作区名字和会话数；右边是「并排」（再加一格：选已有会话或新开）和右侧栏按钮。

平铺的交互照搬 Bento（`~/code/bento/modules/BentoWorkbench`、`BentoShellMac/TiledPaneHost_macOS.swift`）。布局数据用它的 LayoutTree。

## 6. Palo 和会话的界面统一

- **左上**：标题胶囊，里面是名字、状态（和文件夹），带一个向下的小箭头。点它弹出这个 agent 的**详情**。
- **右上**：只有一个按钮，用来打开右侧栏。
- **详情**：在 Mac 和 iPad 上是从胶囊下面弹出的玻璃浮层，在 iPhone 上是从底部升起的半屏面板。平铺时，每一格的标题胶囊弹出各自的详情。内容如下：
  - 名字（可改）、状态
  - 文件夹：文件（在右侧栏打开文件树）、在访达里打开、在终端里打开
  - 模型、思考深度
  - 上下文用了多少，以及「压缩」
  - 后台任务和子 agent，每一项都能单独停
  - 本次用量
  - 所在工作区：并排…、移到…
  - 结束这个会话
  - Palo 的详情里另外有目标、履历、记忆三块，就是现在「它」那一页的内容。
- **停止**：它在干的时候，输入框右边的麦克风换成停止键。这时仍然可以说话或打字，会排队成下一句。
- **工具步骤和代码改动**：默认收成一行，点开看每一步和 diff。
- **后台任务**：有在跑的，对话里显示一条，点开就是详情里的那一块。
- **Palo 转来的话**：在会话里标出「Palo 转来的」；Palo 那边标出「发给了 X」。

## 7. 右侧栏

- 默认收起。打开链接、文件或成果时自动弹出。
- 只做「浏览器」：网页标签、文件预览、文件树、成果。**不放详情。**
- 第一个标签固定：在 Palo 页是**成果**；在会话页和工作区里是**文件**，也就是那个文件夹的文件树。点文件就在旁边开一个预览标签。
- 每个工作区、每个会话、Palo 页，各自记住自己的标签，以及右侧栏是开还是关。同一个工作区里，平铺和单开某一格共用同一组标签。
- 网页标签切换时不重新加载（照搬 Bento 的 PreviewDock）。
- iPhone 没有右侧栏：右上角的按钮打开一整页，内容相同。

## 8. 侧栏收起

- 工具栏最左的侧栏按钮，或 ⌃⌘S。侧栏开关是全局的，不按工作区分别记。
- 收起后，红绿灯旁边留一个玻璃小胶囊：侧栏按钮、小号 Palo 球，以及「N 等你 · N 做完」（没有就不显示）。点它弹出列表，点一项就跳过去。如果那个会话在当前工作区里，就把它设成当前格。
- 鼠标移到窗口最左边时，侧栏从左边浮出来，盖在内容上，不挤压内容；鼠标离开就收回。在 iPad 上是从左边缘往右划。

## 9. 新建

- **新建会话**：⌘N，或者侧栏 ＋。弹出最近用过的文件夹列表，当前会话的文件夹排第一，回车就开；可以搜索，也可以选别的文件夹。在工作区里按 ⌘↩，就作为新的一格加进当前工作区。新会话先不起名，按第一句话自动起名，之后可以改。
- **新建工作区**，入口都要看得见：
  1. 会话详情里的「并排…」：选一个已有会话或新开一个，和当前会话组成一个新工作区，名字先用第一个会话的名字。
  2. 侧栏 ＋ → 新建工作区：勾选几个会话，或者先建一个空的。
  3. 右键一个会话 → 移到工作区 → 已有的工作区，或「新建工作区…」。⌘ 多选后右键 →「用这几个新建工作区」。
  4. ⌘⇧N。
  5. 在侧栏里把一个会话拖到另一个会话上（熟练以后用的快捷方式）。

## 10. 沉浸感（Liquid Glass，iOS / macOS 27）

- 对话一直通到窗口（或者那一格）的最上和最下。工具栏、标题胶囊、输入框都是浮在内容上的玻璃。滚动时内容从它们下面穿过。
- 滚动到边缘时只做轻微的模糊和变暗，**不用实心的条**。
- 侧栏是浮着的玻璃面板。主题色只用在：Palo 小球、当前格的边框、最主要的按钮。
- 优先用系统控件和系统的 glass 效果，不自己画。

## 11. 语音

- 每一格、每一页都用现在 Palo 输入框的长按说话。
- 球就是 Palo，只有对 Palo 说话时才出现：
  - 在 Palo 页按住：球从侧栏的 Palo 那一项（侧栏收起时从左上的小胶囊）飞出来，悬在对话区上方听你说；松手后飞回去。只有对话区变暗。
  - 在某一格或某个会话页按住：不出现球。这一格变暗；标题胶囊上的状态点变成跟着声音跳动的小音量条，边框随声音微微发亮；说的字出现在这一格中间，三个松手区域在这一格的输入框上方。

## 12. iPhone

- 首页就是第 4 节那棵树：Palo 大卡片、工作区（可以展开）、会话、以前的、Allies。左上是设置，右上 ＋ 新建会话。
- 打开 App 时直接进 Palo 对话（和现在一样），左上角返回到首页。
- 会话页和 Palo 页一样：中间是标题（点开是详情半屏面板），右上是文件和成果的按钮。
- 不做平铺。

## 13. iPad

和 Mac 一样。屏幕放不下三格时（11 英寸或竖屏），最多并排两格，其余的收进标题栏的切换里。

## 14. 数据放在哪

- 工作区（名字、成员、布局树、右侧栏标签）、会话的「做完了 / 已看过」状态、自动收起，都由**主机**保存。这样手机和 Mac 看到的是同一棵树。
- 侧栏开关、窗口大小这些只跟本机有关，存在 App 本地。

## 15. 不做

- 不在 PaloAlly 里再造一个终端。普通 shell 从详情里的「在终端里打开」进入。
- 不做「真正的浏览器」那一套（书签、历史同步）。
- 不加开发者开关。会话的这些能力对所有人都在，只是不写代码的用户用不到。

## 16. 还没定（按本文的默认先做）

- 「以前的」自动收起的天数：默认 3 天。
- iPad 放不下时的处理：见第 13 节。
