# Fixtures

`protocol.json` — written by the host test suite (host-owned; don't edit it
here). `{ "methods": { "<method>": { "params", "result" } }, "events": { "<event>": payload } }`,
produced by driving a real Hub through every RPC method and event.
`ProtocolContractTests` checks it strictly. `protocol.sample.json` is the
client's hand-written stand-in, used when `protocol.json` is absent (or when
`PALOALLY_PROTOCOL_FIXTURE=sample`).

`e2e-vectors.json` — cross-implementation E2E vectors generated by the host
(TypeScript) side. `InteropVectorTests` runs them when the file exists and
skips otherwise. Accepted shapes: one object, an array of objects, or
`{"vectors": [...]}`.

| field | meaning |
|---|---|
| `device_seed_hex` | device Ed25519 private key, 32-byte raw seed |
| `host_seed_hex` | host Ed25519 private key, 32-byte raw seed |
| `eph_c_seed_hex` / `eph_h_seed_hex` | client / host X25519 ephemeral private keys, 32 raw bytes |
| `eph_c_pub_b64` / `eph_h_pub_b64` | the matching X25519 public keys (base64, std or url) |
| `client_sig_b64`? | Ed25519(device, `"paloally-hs1|c|" + eph_c`) — verified, not compared (CryptoKit signs randomized) |
| `host_sig_b64`? | Ed25519(host, `"paloally-hs1|h|" + eph_c + eph_h`) — verified |
| `device_pub_b64`? / `host_pub_b64`? | raw Ed25519 public keys |
| `device_ssh_wire_b64`? | `[u32 11]"ssh-ed25519"[u32 32][raw32]`, standard base64 |
| `k_c2h_hex` / `k_h2c_hex` | HKDF-SHA256(ikm=X25519 shared, salt=eph_c‖eph_h, info="paloally c2h"/"paloally h2c", 32) |
| `plaintext` | UTF-8 string sealed in both directions |
| `c2h_unit0_hex` | full unit: `0x02 ‖ ciphertext ‖ tag16`, client→host, counter 0 |
| `h2c_unit0_hex`? | same, host→client, counter 0 (opened by the client) |
