PaloAlly 让你已经在用的 Claude Code 常驻在自己的电脑上。你离开电脑，它接着办；需要你的时候，它在手机或微信上找你；它也记得你。 PaloAlly keeps the Claude Code you already use running on your own machine. Step away and it keeps working. When something needs you, it finds you on your phone or in WeChat. And it remembers you.

它和你It and you

两滴玻璃，
一滴是它，一滴是你。 Two drops of glass.
One is it. One is you.

PaloAlly 没有脸。它用两滴彩色玻璃告诉你它在做什么：你说话时，你的那滴跟着声音起伏；它在想事，两滴分开绕转；办完了，它们撞在一起，再分开。 PaloAlly has no face. Two drops of colored glass show you what it’s doing: when you talk, yours moves with your voice; while it thinks, they part and circle; when it’s done, they meet, and part again.

开始Get started

三步装好。Three steps.

需要 macOS 或 Linux，以及 Claude Code（claude.ai 登录或 API key 都行）。运行时 Bun 由安装脚本自动装好。 You’ll need macOS or Linux and Claude Code, signed in with claude.ai or an API key. The installer sets up Bun for you.

  1. 1

    安装Install

    会问你几个问题，最后发一条很短的消息，确认模型能用。It asks a few questions, then sends one short message to check the model works.

    bash -c "$(curl -fsSL https://raw.githubusercontent.com/NovaShang/palo-ally/main/install.sh)"
  2. 2

    让它常驻Keep it running

    装成开机自启的后台服务。Installs a background service that starts when you log in.

    paloally service install
  3. 3

    配对 AppPair the app

    在 PaloAlly App 里扫屏幕上的二维码，或者粘贴配对链接、输入 6 位配对码。想用微信，再运行 paloally wechat login。In the PaloAlly app, scan the code on screen, or paste the pairing link and enter the 6-digit code. For WeChat, also run paloally wechat login.

    paloally pair

关于 AppAbout the app Mac 版可以直接下载，用 Developer ID 签名并经过 Apple 公证，需要 macOS 26 或更高。iPhone 版还没有上架 App Store，现在需要用你自己的 Apple 开发者账号，从仓库的 ios/ 目录编译安装。微信入口不需要 App。 The Mac app is a direct download, signed with Developer ID and notarized by Apple; it needs macOS 26 or later. The iPhone app isn’t on the App Store yet: for now, build it from ios/ with your own Apple developer account. The WeChat channel works without either.
